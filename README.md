# Next Word Prediction Using Deep Learning

## Project Overview
A Deep Learning-based Next Word Prediction system that predicts the next possible word based on user input.

## Models Implemented
- Simple RNN
- GRU
- LSTM

## Technologies Used
- Python
- TensorFlow / Keras
- Streamlit
- NumPy
- NLP
- Deep Learning

## Model Performance

| Model | Accuracy |
|---|---:|
| Simple RNN | 86.39% |
| GRU | 85.05% |
| LSTM | 79.9% |

## Project Structure

- app.py – Streamlit application
- train.py – Model training
- predict.py – Next-word prediction
- compare_models.py – Model comparison
- dataset/ – Training dataset
- model/ – Trained model
- accuracy_comparison.png – Accuracy graph
- loss_comparison.png – Loss graph

## How to Run

1. Clone the repository.
2. Install dependencies:

   pip install -r requirements.txt

3. Start the application:

   streamlit run app.py

## Features
- Next-word prediction
- Three deep learning architectures
- Model performance comparison
- Interactive Streamlit interface
